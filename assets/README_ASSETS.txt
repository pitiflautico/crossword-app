ASSETS REQUIRED
===============

Please add the following image assets to this directory:

1. icon.png (1024x1024px)
   - App icon for both iOS and Android
   - Should feature the crossword/puzzle theme

2. adaptive-icon.png (1024x1024px)
   - Android adaptive icon
   - Transparent background with icon in center

3. splash.png (1284x2778px recommended)
   - Splash screen image
   - Background color: #00A3E0 (matches app theme)

4. favicon.png (48x48px)
   - Web favicon

You can use any icon generator tool or design software to create these assets.
For quick testing, you can use placeholder images from:
- https://via.placeholder.com/1024x1024/00A3E0/FFFFFF?text=Crossword
